Apa Itu Exploratory Data Analysis?
Konsep Inti
EDA adalah proses memahami bentuk, 
kualitas, pola, dan anomali data 
sebelum model machine learning 
dibangun.
ò Mengubah dataset mentah menjadi informasi yang 
dapat dijelaskan.
ò Membantu memilih fitur relevan untuk kasus keamanan.
ò Mengurangi risiko data leakage, bias, dan salah 
interpretasi.
ò Menjadi dasar keputusan preprocessing dan evaluasi.

Data Dictionary: Kamus Sebelum Analisis
Praktik Wajib
Kolom yang tidak dipahami akan menghasilkan model yang sulit dijelaskan. Data dictionary

ò Nama fitur: duration
ò Tipe data: numerik

ò Catatan: perlu cek outlier

ò Pilih minimal 5 fitur utama.
ò Jelaskan makna keamanan setiap fitur.
ò Tandai fitur yang menjadi label.

Cek Kualitas Data Keamanan
Data Profiling
ò Missing values: data kosong pada kolom penting.
ò Duplikasi: baris berulang yang mengganggu evaluasi.
ò Outlier ekstrem: nilai tidak wajar pada durasi, bytes, atau 
packet count.
ò Distribusi label: proporsi normal dan serangan.
ò Tipe data salah: angka terbaca sebagai teks atau waktu 
tidak terformat.
ò Data leakage: fitur yang membocorkan label secara tidak 
sah. Misal: password dan username
Security data sering besar, tidak seimbang, 
dan mengandung noise. Kualitas data 
menentukan kualitas deteksi.

Distribusi Label dan Class Imbalance
Kelas Normal vs Serangan
Pada kasus keamanan, data normal sering jauh lebih banyak daripada data serangan. 
Accuracy saja dapat menyesatkan.
Contoh distribusi label:
Normal: 8.600
DoS: 940
Scan: 620
Brute Force: 310
Botnet: 120
ò Periksa jumlah data tiap label.
ò Catat kelas minoritas dan mayoritas.
ò Hubungkan imbalance dengan false 
negative.
ò Rencanakan metrik selain accuracy.

Missing Value, Duplikasi, dan Outlier
Kualitas Data
MISSING VALUE
ò Dampak: model tidak stabil atau 
gagal dilatih.
ò Keputusan: drop, imputasi, atau 
investigasi.
DUPLIKASI
ò Dampak: evaluasi tampak terlalu 
baik.
ò Keputusan: hapus data duplikat.
OUTLIER
ò Dampak: skala fitur dan batas 
keputusan bergeser.
ò Keputusan: analisis, transformasi, 
atau clipping.
Semua keputusan pembersihan data harus dicatat pada notebook agar eksperimen 
dapat direplikasi.
